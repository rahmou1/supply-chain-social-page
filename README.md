Supply Chain Department — صفحة روابط السوشيال ميديا

المحتويات:
- index.html: صفحة جاهزة فيها روابط WhatsApp وInstagram وTikTok وFacebook.

مهم:
لكي يعمل QR Code عند أي شخص، يجب رفع الصفحة على رابط عام على الإنترنت أولاً.
طريقة سهلة ومجانية:
1) افتحي https://app.netlify.com/drop
2) اسحبي مجلد الموقع أو ارفعي ملف ZIP الخاص بالموقع حسب الخيارات الظاهرة.
3) بعد النشر، انسخي رابط الموقع العام الذي يعطيه Netlify.
4) ابعتي الرابط هنا وسأجهز لك QR Code يفتح الصفحة مباشرة.

ملاحظة: راجعي الروابط بعد النشر للتأكد أنها تفتح الحسابات/المجموعات المطلوبة.
